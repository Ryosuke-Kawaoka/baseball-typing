タイピング ホームランチャレンジ v27 クリーンアップ版

【方針】
新機能は追加せず、v26までの機能を維持しながらコードを整理しました。

【主な整理】
・style.css の重複上書きを廃止し、最終スタイルだけに一本化
・script.js を「単語」「ローマ字」「球場/見た目」「ゲーム」「タイム」「イベント」に分割整理
・同名処理、二重イベント登録、二重 disabled 設定などを除去
・DOMイベント登録を init() に集約
・localStorage / IndexedDB の保存キーは既存版と互換性を維持
・背景、投手、キーボード、出題文字の位置調整を一つの appearance 処理に統一
・キーボードは次に押すキーだけを表示（入力済みキーの色演出なし）

【維持している主な機能】
・10球ホームランチャレンジ
・5/7/10/20秒
・タイム機能
・0ミス=HR、1〜2ミス=ヒット、3ミス以上=空振り
・柔軟ローマ字（し=shi/si、しょ=sho/syo、ん=n/nn、ディ=dhi/dxi など）
・同じ単語の連続出題防止
・単語登録（最大100）
・キーボード次キーガイド
・投手10フレームアニメーション
・確信ホームラン30%
・球場背景切替
・球場画像追加/削除
・背景/投手/キーボード/出題文字の位置・サイズ調整

【GitHub Pages】
index.html / style.css / script.js と画像・音声・pitcher_frames をすべて同じ構成で上書きしてください。
